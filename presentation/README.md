November 2026), paper 69.

`LACCI2026_paper69_presentation.pdf` — 15 slides.

A rendered page with the deck embedded is published at
<https://rfapo.github.io/lacci2026-lightweight-gan-tradeoff/>.

## Note on one figure

This web copy differs in a single figure from the version shown at the
conference. Slide 3 illustrates COVID-19 blood-film lymphocyte anomalies; the
conference version reproduced a figure from a copyrighted journal article under
academic citation, and this copy uses an openly licensed equivalent instead
(Karapetyan et al., *Heliyon* 10 (2024) e24527, CC BY 4.0), so that the deck can
be redistributed without restriction.

Every other figure is either the authors' own or openly licensed; credits are
printed beneath each image in the deck itself.
